# Clube Xeque-Mate

Site institucional de um clube de xadrez.

## Arquivos

- `index.html`: estrutura e conteúdo do site.
- `style.css`: estilos, cores e responsividade.

## Como visualizar

Abra o arquivo `index.html` no navegador. É necessário estar conectado à internet para carregar as fotografias externas.

## Validação HTML

1. Publique o site ou abra `https://validator.w3.org/nu/`.
2. Escolha **Check by URL** e informe a URL do `index.html` publicado, ou use **Check by File Upload** e envie o arquivo.
3. Corrija qualquer mensagem apresentada até obter **Document checking completed. No errors or warnings to show**.
4. Faça uma captura de tela do resultado sem erros e salve-a nesta pasta com o nome `validacao.png`.
5. Mantenha a captura junto deste README para comprovar a validação.

> A captura de validação precisa ser feita depois de validar a versão final. Ela não foi incluída porque o resultado depende da validação real do arquivo publicado.

## Publicar no GitHub Pages

1. Entre no GitHub e crie um repositório público, por exemplo `clube-de-xadrez`.
2. Envie `index.html`, `style.css` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`; clique em **Save**.
6. Aguarde a publicação. O endereço ficará no formato `https://SEU-USUARIO.github.io/clube-de-xadrez/`.

## Personalização

O endereço, e-mail, horários e data de encontro são exemplos e devem ser ajustados aos dados reais do clube. O formulário usa `mailto:` e depende de um programa de e-mail configurado no dispositivo; para receber mensagens diretamente pelo site, será necessário um serviço de formulário ou backend (sem JavaScript também é possível usar um serviço externo).
