# Site-clube-de-xadrez
lang, meta viewport e title próprio; header, nav, main, aside e footer usados corretamente
Hierarquia de títulos sem saltos (um h1) e pelo menos 3 article com conteúdo do seu tema
Pelo menos 3 imagens em figure + figcaption, com alt adequado, width e height
Uma tabela com caption, thead, tbody e th com scope
Um formulário de contato com label em todos os campos, types corretos e fieldset/legend
Uso de time, address e strong/em onde fizer sentido; link “pular para o conteúdo”
Zero erros no validator.w3.org/nu (print no README)
CSS externo simples e responsivo; site publicado no GitHub Pages
